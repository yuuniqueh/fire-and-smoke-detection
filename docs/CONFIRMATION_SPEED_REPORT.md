# 确认速度试验与操作

2026-10-11。已加入可选快速档，标准档仍为默认。此次没有训练模型，也没有运行新数据泛化实验。

## 如何使用

重新打开桌面软件，在“分析配置 → 确认速度”选择“快速响应 · 稳定约 0.5 秒”，再开始分析。选项自动保存；分析过程中不能切换。恢复默认会回到标准观察。命令行可加 `--confirmation-profile fast`，默认仍是 `standard`。

快速档在原标准通道之外增加短窗口：同一关联区域近 0.5 秒有至少 0.45 秒正证据、持续率至少 90%、至少 4 次真实采样，并且窗口内相邻采样间隔不超过 0.2 秒。当帧也必须检出。检测断续、采样不足时继续按原标准条件判断。

这里的 0.5 秒指稳定检测窗口，不是从真实起火到提醒的保证时长；模型首次检出、区域接续、视频处理速度也影响响应。巡检跳过的帧不会补成正证据。标准通道、风险升级等待和提示冷却分别保留原行为。
