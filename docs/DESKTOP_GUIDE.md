# 桌面版使用说明

2026-10-20 首页更新：默认进入“实时监测”，先连接预览，再开始监测。导入录像位于“工具 → 录像分析”，历史与录像存储也可从工具进入。右侧仅保留当前状态、必要的核查操作和提示音控制；“检测详情”展开指标，“提示说明”解释颜色与已查看的含义。无事件时不显示空时间轴和无效核查按钮。预览不会启用检测；画面未更新与历史记录会明确标注。详见 [精简界面说明](CONCISE_MONITORING_UI.md)。

场景选择：在“实时监测 / 录像分析”的“检测场景”中选择通用监看、家庭室内、林地远景或无人机巡林。后三项是真实场景模型试用；家庭和林地模型曾未通过旧困难图筛查，需要现场录像验证。点击“更多模型”可打开简洁卡片；反光和火焰对照放在“高级对照”。完整来源和取舍放在“查看介绍 / 模型介绍”。运行中锁定，选择自动保存，记录与报告保留实际使用的方案。文件缺失时禁止开始，不自动下载或回退。详见 [按场景选择检测方案](SCENE_MODEL_SELECTION.md)。

提示等级已更新为黄色“请核查”、橙色“优先核查”、红色“立即核查”，配合色条和感叹号。历史记录使用灰色卡片并注明“当时提示”；“设置”内可开启橙 / 红新提示声音并点击“试听提示音”。硬件声光设备暂未接入，详见 [提示等级与声光方案](ALERT_DESIGN.md)。

2026-10-19 新版操作以本节为准，下面的 2026-10-12 内容保留为旧版说明。新版为源码更新，双击 `start_desktop.cmd` 启动；现有便携 EXE/ZIP 未重建。验收与限制见 [交互改版记录](UX_REDESIGN_TEST_REPORT.md)。

1. 本地录像：左侧“视频分析” → “选择视频”或“试用示例” → “开始分析”。摄像头：左侧“实时监看” → 选择设备 → “连接预览” → 核对画面后“开始监看”。预览不检测、不录像。
2. 查看首页提示、中文检测框和近期事件时间轴；点击色块或“查看事件详情”进入事件核查。指数、贡献等在“展开详细分析依据”内。
3. “已知悉”只记录看过提示；在核查表单中选择判断、填写备注并“保存核查结果”。“无法判断”和“需进一步核实”保留待跟进；“疑似误报”为人工意见，保留原证据。
4. 结束并保存本次检测后，在事件页“回看事件片段”，可选择原视频或标注录像并逐帧、拖动或变速回放。新记录以原画面截图叠加中文框展示，旧记录继续使用原有截图。
5. “导出分析报告”生成可读 Markdown；“导出完整记录”生成含日志和证据的 ZIP。报告 / ZIP 导出需要该次检测结束并保存。
6. “暂时静音 5 分钟”仅关闭本机提示音，可随时恢复；“设置”中的技术参数默认折叠，“录像与存储”用于保护和清理记录。

预览、实时检测、视频分析和历史回放具有独立标识。画面延迟或未更新时会明确提示，旧画面和未知数据不表示现场安全。

确认速度：在“分析配置”可选择标准观察或快速响应。快速档增加约 0.5 秒的稳定检测通道，旧开发回放中也增加了误提示；标准仍为默认。具体案例、时间和误报代价见 [确认速度试验](CONFIRMATION_SPEED_REPORT.md)。

2026-10-11 产品功能更新：设置集中在“分析配置”页；新增“趋势观察”和“提示中心”、可选本机声音、人工确认/误提示记录、节能监测试用模式。新功能完整说明见 [软件框架与使用说明](PRODUCT_FRAMEWORK.md)。默认完整检测和原检测/关联方案保持不变。

## 启动与分析

1. 双击根目录 `start_desktop.cmd`。也可以在项目终端运行 `.\.venv-pytorch\Scripts\python.exe desktop.py`。
2. 点击“壁炉示例”，或“打开视频”选择本机素材。
3. 默认自动选择 GPU/CPU，检测阈值为 0.35；点击“开始分析”。加载模型期间仍可点击停止。
4. 左侧显示最新处理画面与曲线，右侧显示当前主导事件的等级、指数、特征及评分贡献。候选未确认时不评分；检测暂缺时保留上次评估并说明。
5. 点击“停止”后等待当前推理结束和记录保存。分析时关闭窗口也会先停止、保存、释放资源再退出。

“按原视频速度显示”开启时，处理够快才等待；性能不足时播放变慢，不为了追赶显示而跳过源视频帧。关闭后尽快分析。视频时间仍按帧序号/FPS 计算，与机器处理速度无关。

上述逐帧推理行为适用于“完整检测”。可选“节能监测（试用）”保留解码/输出的全部视频帧，但巡检间隔不运行检测，日志明确记为 `observed=false`。疑似目标触发加强分辨率逐帧检测，另有定期高分辨率巡检；这会改变漏提示与延迟，需要单独验证。界面检测次数统计不是实测电量。

“检测方案”默认选择“原模型”。也可选择“减少反光误报（候选）”：使用新模型识别火焰、原模型识别烟雾，固定阈值 0.35。它减少了开发素材中的亮光误确认，但部分火焰可能更迟确认或中断；并非全面优于原方案。分析中不能切换，结束后可切回原模型。权重需提前按 README 准备；所选模式和模型来源随结果保存。检查记录见 `FUSION_RUNTIME_REPORT.md`。

预览和曲线是显示采样：界面每 50ms 获取最新画面，曲线最多保留最近 120 秒、约每 0.1 秒一个点。未确认区间不画成已评估的零风险。完整逐帧结果照常保存；事件表的峰值来自后台累计，不从采样曲线推算。

## 事件与历史记录

在“检测方案”选择“减少反光误报（候选）”后，可将“事件关联”从“原关联”切换为“稳定区域（候选）”。它让同一处火焰的局部框接续证据，原 1.5 秒窗口、1 秒观察、0.8 秒正检测、70% 比例及 0.6 秒超时条件不变。切回原模型会自动恢复原关联；运行中两项均锁定。它是开发验证候选，不能保证所有场景更快；具体对照见 `EVENT_REGION_VALIDATION_REPORT.md`。默认启动仍为原模型与原关联。

- 事件确认时，自动保存 `evidence/event-N.jpg`。文件为确认时刻的检测/时序画面，最高风险指数可能发生在其他时刻。
- 事件表显示最近 200 条；所有已确认事件仍保存在 `events.json` 中。点选事件查看时间、峰值依据及结束原因，点击“回看事件前后”打开回放，“查看并处理提示”进入人工处理。
- “历史分析”页支持按视频名或运行时间筛选。选中记录，点击“查看选中记录”；曲线与事件会重新载入。
- 在历史记录中点选有截图的事件，左侧显示确认截图，右侧明确标注历史峰值时刻。旧版本记录没有截图时，可以从结果目录查看输出视频。
- “结果目录”打开本次或选中历史分析的文件夹。

结束时间是软件事件边界，视频结束和手动停止均不能说明实际火情结束。历史汇总也不代表当前实时状态。

## 导出

分析结束或载入历史记录后，点击“导出记录 ZIP”，选择保存位置。导出在后台执行；不能将 ZIP 保存进被导出的运行目录。

导出包包含已存在的输出视频、检测/时序/风险日志、CSV、事件、配置、总结和证据截图，以及可读的 `事件复核报告.md`。原视频和模型权重不复制进包。ZIP 中使用相对文件名，写入临时文件成功后替换目标文件。

新版本还包含趋势日志、最后观察趋势、调度日志、分级提示及人工反馈。回看趋势显示历史观察时刻，不代表当前状态。人工确认表示已经查看提示，误提示标记是用户反馈，均不自动改动模型或数据真值。

这是分析记录包，不是可安装的软件包，也不是已按匿名规则整理好的参赛材料。配置保留原机器的输入路径和模型来源；正式参赛材料仍需单独整理、核对身份信息及第三方授权。

## 常见情况

- 模型不存在：按 README 准备 `models/best.pt`，界面不会自动联网下载。
- GPU 不可用：选择“仅 CPU”再试。
- 无法读取视频：重新选择可播放、可解码的视频；文件后缀正确不代表内容有效。
- 帧数差异：壁炉 WebM 的容器报告 207 帧、实际解码 206 帧，已保留提醒，详见 `summary.json`。
- 曲线为空：未确认事件，或该历史记录属于单帧/仅时序模式。
- 启动失败：命令窗口保留错误；桌面入口异常也记录到 `outputs/desktop-startup-error.txt`。

建议使用至少 980×740 的可用窗口空间。界面可调整分隔线，右侧内容较长时滚动查看。

## 当前边界

支持本地分级横幅/提示记录及可选系统提示音。已增加 Windows 摄像头入口，真实设备待验收；没有外部消息报警、视频音频播放、安装包或数据库服务。支持本地视频、输出文件与本机历史查询。仍需用户检查文件对话框、系统声音、缩放及使用体验，并补充真实场景、长视频、CPU 与新机器测试。

指数是启发式视觉指标，不是经过校准的火灾概率。框覆盖不是燃烧面积。“无确认事件”不等于现场安全。
