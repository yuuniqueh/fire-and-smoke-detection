# 监控卡片与事件导航

日期：2026-11-17。双击项目根目录的 `start_desktop.cmd` 或 `start_monitor_center.cmd` 使用。已打开的旧窗口需要关闭并重新启动；旧便携EXE尚未重建。

## 使用方式

1. 点击任一路监控画面、卡片文字或“查看详情”，右侧打开本路的视频场景分析。没有烟火检测事件也可以查看AI画面理解。尚未开播或尚无完整结果时显示等待状态，不补造描述或事件。
2. 点击下方事件行，右侧切换到该事件的描述、最终研判、数据和人工核查操作，同时高亮对应监控点。
3. 事件列表新增序号，以及优先级、时间正序／倒序、监控点名称四种排序。点击相关表头也可切换排序。排序与筛选不改变已分配的序号；新增事件不使已显示事件改号。序号用于当前界面导航，原始检测事件编号保留在展开详情中。
4. 点击事件会自动扩大事件区域；“展开事件区／收起事件区”可手动切换，也可拖动监控画面和列表之间的分隔条。窄窗口仍保留列表的最低操作空间，因此可展开幅度取决于可用高度。

点击卡片后，新增事件、列表刷新和排序均保留当前视频场景选择。模型设置、开始／停止按钮保留各自操作，不触发卡片选择。展开、排序和选择不会重新启动或停止监测任务。

滚动位置补充修复：后台刷新只更新有变化的单元格，不再反复重新选中原事件。拖动滑条和松开后均保持浏览位置；新增事件或优先级重排时，尽可能保持原来顶部可见事件的位置，事件移出当前筛选范围时按可用范围调整。自动监测继续运行。

## 时间与结果含义

优先级排序先列未完成事项，再按已保存的最终等级从高到低；同等级待处理事项先于待核查事项，已完成事项置后。不会按数字评分在界面重新划分等级。

本地录像的“发现时间”是录像中的位置。跨记录的时间排序依据可用记录时间和录像位置；它不代表导入视频的真实拍摄日期或实际起火日期。

卡片打开的是同一监控点、同一段录像的最新可用场景观察；运行中排除尚未播放到的未来证据。原画面按留存图像及哈希核对。场景本身没有告警时，不会为了显示详情创建待核查事件。已保存结果明确保留历史标识，辅助评分仍不代表火灾概率。
