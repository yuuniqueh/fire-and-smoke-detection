# 源码与许可

焰鉴应用代码由卡卡队采用 AGPL-3.0-only 方式交付。根目录 LICENSE 为完整条款，NOTICE 为应用及第三方边界说明。允许依该许可修改及再分发；软件不提供保证。第三方库、模型和数据保留各自适用的条款及版权，不能据此称为本项目自主研发网络。

应用源码在软件根目录 application-source.zip。实际构建脚本、CPU 依赖清单、配置和测试随源码提供。对应第三方源码位于软件根目录 corresponding-sources，source-manifest.json 记录各档案的版本、来源 URL、大小及 SHA-256。获取本软件时应同时取得该源码目录；重新分发软件须保留等效的源码取得方式和适用声明，不只转发单独 EXE。

第三方许可文本在 third-party-notices 和 licenses。Qt 库以可替换 DLL 形式分离提供，未设置禁止用户为调试修改而逆向工程的附加限制。用户可以依许可修改源码和替换匹配版本的库；重建方法见 BUILD_FROM_SOURCE.md。源视频、个人设置、监控记录和训练数据不属于应用源码交付范围。

模型为第三方已训练权重。原模型固定来源声明 AGPL-3.0；亮光候选提供 MIT 文本；YOLO26-S 候选在固定模型卡声明 MIT。对应来源及文件校验记录与权重一同保存。模型发布者声明不等于本项目独立认证训练素材权利，不将其指标作为本项目测试结果。

0.2.0-rc1 另包含家庭室内、SAINet 林地远景与无人机火焰场景权重，各固定来源声明 AGPL-3.0，模型卡、来源版本与哈希随对应目录保存。dill 0.4.0 用于加载家庭场景检查点，其安装包、许可文本与上游源码纳入本次构建记录及交付材料。

本交付按“附带应用与对应第三方源码”的方式准备，不以承诺日后按请求提供源码的书面要约代替当前文件。源码档案包含上游构建说明；本项目验证的是应用级重建与工程功能，不宣称重新编译过所有上游 C/C++ 库或实现了二进制逐字节复现。
