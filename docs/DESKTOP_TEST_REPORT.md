# 桌面版本阶段验收

日期：2026-10-06。本机 Python 3.9.25、PySide6 6.9.3、已有 PyTorch/RTX 4060 Laptop。不是跨机器或消防可靠性验收。

## 完成内容

桌面入口、视频选择、设备/检测阈值、开始/停止、最新画面、进度、风险与解释、最近 120 秒曲线、事件表、确认截图、历史筛选/读取、ZIP 导出。

命令行和桌面共同调用 `core/pipeline.py`，检测/时序/风险算法未复制成另一套。推理、历史曲线读取及导出使用后台 QThread，Qt 窗口在主线程刷新；预览只保留最新帧，曲线内存有界。停止通过协作标志完成，不强制终止线程。

## 检查结果

原有 38 项时序/风险测试与新增 5 项记录/导出检查，共 43 项全部通过。新增检查包括 ZIP 相对路径和证据、排除无关文件、拒绝导出到源目录内、未完成记录不覆盖既有导出、坏历史跳过与曲线时间窗口。

实际 Qt 控件及真实模型的 10 项集成检查通过：

1. 不存在的视频被拒绝。
2. 运行期间不能重复开始或修改输入参数。
3. 壁炉完整处理 206 帧、确认 1 个 fire 事件、最高生效 LOW，确认截图生成。
4. 推理期间 Qt 主线程定时器持续响应；最近一次检查最大 20ms 定时器间隔为 0.0635 秒。只描述本次短视频运行。
5. 点击停止后输出总结、关闭事件、释放资源。
6. 再次分析合成无火视频，45 帧、0 事件，之前状态清空。
7. 内容无效的 MP4 在后台报错后控件恢复。
8. 历史筛选、载入曲线、事件截图与详情可用。
9. 实际导出 ZIP 可读取、CRC 检查通过，含证据和一致的总结。
10. 分析中关闭窗口，等待协作清理后退出，没有遗留推理线程。

集成检查使用 Qt 的 offscreen 平台，但运行实际窗口控件、事件循环和本地模型；不是静态界面图。Windows 原生文件选择/保存对话框、桌面缩放和人工操作体验仍需实际试用。1280×920 和 980×740 布局截图已查看；文字使用本机微软雅黑，测试时注册系统字体，未复制字体进行分发。

实时事件峰值直接来自核心累计值，避免预览采样漏掉峰值；历史峰值时刻与确认截图时刻分开标注。曲线采样不替代完整逐帧日志。
