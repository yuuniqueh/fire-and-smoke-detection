# 事件核查与处理

2026-10-11。本轮完善本地视频的使用流程，不调整检测模型、时序确认条件或风险评分规则。

## 收到提示后怎么操作

1. 在“提示中心”选中提示，点击“定位到事件”，查看确认时间、最高指数和结束原因。
2. 点击“回看事件前后”。从事件进入时定位到确认时刻；从提示中心点击“回看提示前后”，则定位到该条提示时刻，例如后续等级升级。
3. 默认回放定位时刻前 5 秒、后 10 秒，按视频边界截取。支持播放/暂停、拖动、前后逐帧、0.5/1/2 倍速和返回定位时刻。初始暂停，便于查看关键画面。
4. 优先显示不叠加本系统预测的原视频，也可切换到含模型标记的检测结果视频。原视频路径失效时，只提供结果中的 `annotated.mp4`；二者都不可用或解码失败时说明原因。
5. 关闭回放，点击“查看并处理提示”，填写可选说明，再点“已知悉”或“标为疑似误报”。“查看确认截图”返回监测总览中的该事件确认截图。

分析中可以查看提示并写入人工反馈；回放须等分析结束，或点击停止并保存后再进入。解码在独立线程执行，不加载模型，不改动分析进度或事件结果。不播放音频，不生成额外事件剪辑文件。

## 处理状态

- 事件表“最新提示处理”对应该事件最新一条需处理提示。新等级提示重新显示待处理，之前的知悉不会自动覆盖它。
- 结束记录显示“无需处理”，不会让已处理事件重新待处理。结束仍只说明软件事件边界。
- 提示中心保留各条提示各自的处理记录。反馈写入 `feedback.jsonl`，历史读取和导出保留，不自动修改模型或真值标注。
- 旧记录没有提示日志时显示“无提示记录”，不表示已被人工处理。

## 查找与导出

事件页支持编号/时间文字查询、类别、最高等级、最新提示处理状态组合筛选，双击事件也能回放。仍显示最近 200 条事件、最近 500 条提示；完整日志保留在结果目录。

历史页可组合视频名/运行时间与完成、停止、失败状态筛选。载入其他记录或开始新分析时重置事件筛选，避免旧筛选隐藏新结果。

ZIP 增加 `事件复核报告.md`，列出全部确认事件、时间、最高等级、最新提示处理状态、截图链接和人工说明。报告处理完整日志，不受界面 200/500 条限制。原视频及权重不打包，结果视频和人工反馈继续按既有白名单导出。

可读报告只显示源视频文件名；既有配置仍可能含原机器路径，正式参赛材料需另行匿名整理。导出包仍是分析记录包，不是安装包。

验证见 [事件核查验收记录](EVENT_REVIEW_TEST_REPORT.md)。
