# 焰鉴 Windows 便携测试版

这是 Windows 10/11 x64 的本地 CPU 兼容测试包，无需安装 Python。它不包含 CUDA；电脑即使有 NVIDIA 显卡，也使用 CPU 推理。实时处理速度需要实测，开发机原有 GPU 环境不受影响。

## 开始使用

1. 将 ZIP **完整解压**到当前用户可写的目录，例如 `D:\FireGuard`。不要直接从压缩包中运行，也不要放在需要管理员写入权限的 Program Files 中。
2. 双击 `FireGuard.exe`，首次启动请等待依赖初始化。0.3.0-rc1的本地AI组件单独封装，将其解压到EXE旁，双击 `启动完整版.cmd` 可先准备AI场景理解再进入软件。无需安装Python。
3. 0.3.0-rc1默认进入监控台，点击“添加监控点”，选择本地录像或摄像头，再开始监测；支持多路管理。点击监控卡片可查看AI画面理解，即使没有烟火事件也可查看。包内不提供个人原始视频。
4. 摄像头输入支持 Windows 本地 USB/虚拟摄像头。安卓手机仍需通过能够提供 Windows 摄像头设备的工具连接；本包没有捆绑该工具或 Android APK。见 `LIVE_CAMERA_GUIDE.md`。
5. 包含通用监看、家庭室内、林地远景、无人机巡林，以及高级页中的反光抑制对照、火焰识别对照，共六套模型或组合方案。初始默认通用模型，每路可独立设置；不会复制开发机的个人选择。介绍保留既有验证结果及限制，不能据此宣称现场准确率提高。

## 文件和记录

- `FireGuard.exe`：主程序。
- `_internal`：必要 DLL、运行库、模型和默认配置。必须与 EXE 一起保留。
- `portable.flag`：便携模式标记。保留它，记录和设置才会保存在同目录的 `data` 中。
- `data/outputs`：运行后生成的监控记录；`data/.cache`：本地设置及缓存。首次交付包不含这两个目录。
- `third-party-notices`：实际构建环境的依赖清单及可找到的 LICENSE/NOTICE/COPYING 文本；这是许可整理材料，不等于已完成公开分发审核。
- `application-source.zip`：本次应用代码、配置、构建脚本、测试和必要文档的快照；不包含训练素材、私人视频、历史记录、Git、个人设置或开发环境。
- `release-manifest.json`：文件大小、SHA256、模型清单及验收边界。

更新时先备份 `data`，解压新版本到独立目录，再复制需要保留的记录；不要覆盖运行中的程序。删除整包也会删除其中的 `data`。存储管理默认不自动删除，手动清理会先展示计划并要求确认；见 `STORAGE_GUIDE.md`。

高级用法：启动前可设置绝对路径环境变量 `FIREGUARD_DATA_DIR`，将运行数据放在其他可写目录。移除便携标记后，默认数据目录变为当前用户的 `%LOCALAPPDATA%\FireGuard`。

## 检查与验收

双击 `检查软件.cmd` 会启动明确标记的工程自检：加载所有登记模型，核对新版首页与模型选择页，处理短视频、保存并回放、导出记录，以及使用合成画面检查摄像头子进程。它会生成自检记录，**不会打开真实摄像头**。这不证明真实火灾准确率或手机连接质量。

换电脑后按顺序验收：正常启动 → 选择视频 → 检测提示 → 停止并保存 → 历史查询 → 回放 → 导出 → 实际 USB/安卓摄像头预览与监控 → 断线和重新连接 → 连续运行与存储增长。记录 Windows 版本、CPU、内存、软件模式、处理速度及问题。新电脑验收尚未完成前，不能宣称“所有电脑即装即用”。

程序启动失败时，查看 `data/outputs/desktop-startup-error.txt`。如果 Windows 系统运行库缺失，先记录完整错误；本项目不要求关闭安全软件或运行不明修复工具。

## 构建

构建使用独立 `.venv-package-cpu`，不修改 `.venv-pytorch`。先安装 `torch==2.8.0+cpu` 和 `torchvision==0.23.0+cpu`（官方 CPU index），再安装 `packaging/requirements-cpu.txt`，最后运行 `python -X utf8 build_windows.py`。默认输出在全新的 `outputs/portable-时间戳`，不会删除或覆盖既有包。PyInstaller 使用目录模式，运行库无需每次解压到系统临时目录。
