# 简约监测界面验收

日期：2026-10-20。用户确认以实时监测为主、本地录像分析为辅助，并要求清理重复文字，尤其右侧底部说明。本轮实现于源码桌面版；重启 `start_desktop.cmd` 查看。

## 使用路径

- 默认打开“实时监测”，不自动打开摄像头、不自动开始检测。
- 侧栏一级入口为实时监测、事件记录、工具、设置。工具默认折叠，内含录像分析、历史记录、录像与存储。进入对应工具会展开该组。
- 摄像头与开始 / 停止按钮位于第一行，场景与模型入口位于第二行。摄像头模式隐藏本地文件框；未运行时隐藏停止按钮。
- 模型文件正常时不常驻显示“文件已找到”；缺失时保留“模型未就绪”，禁止开始。

## 精简与渐进显示

原界面在标题、状态条、黄色横幅、视频空画面与右侧卡片反复描述相同操作。现在状态移到标题右侧，监测页隐藏重复副标题，无事件时不显示黄色占位横幅、空时间轴、无效核查按钮和导出按钮。

右侧默认是一张随内容自然增高的状态卡。未开始时只显示等待状态、提示音开关和提示说明。有事件后显示颜色名称、明确核查动作、疑似类别 / 持续时间、“查看事件详情”和“标为已查看”。说明性长段落移到独立的“提示说明”窗口；视觉指数、框占比、时长、置信度、评分与诊断信息放在默认折叠的“检测详情”。

提示音开关可在空闲时直接调整；运行中沿用该次配置并锁定开关，避免界面显示开启而工作线程没有声音通道。开启提示音后提供“静音 5 分钟”和恢复倒计时；静音不停止检测与视觉提示。没有提示音时不显示无效静音操作。

“标为已查看”仍写入原 acknowledged 反馈，保持待核查语义，不自动视为核查完成。对应说明可在按钮提示与“提示说明”中查看。

## 关键状态继续明确显示

- 预览：显示“仅预览”“尚未启用检测”，并提示开始监测。
- 等待观测：显示本帧未检测，清空当前指标。
- 延迟 / 未更新：保留醒目的画面标签和“当前现场状态未知”，清空当前指标。
- 连接失败 / 中断：错误栏显示原因，状态卡明确“连接已中断”“检测未运行”。预览停止后不称为正在检测。
- 历史：保留“历史记录 · 非实时”、当时等级和灰色样式；不响铃。
- 正在运行的事件：保留颜色、感叹号、核查动作和证据入口；数值解释折叠不影响事件提示。
