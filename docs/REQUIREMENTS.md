# 首版需求与验收

当前已实现本地视频检测、时序事件确认、动态风险解释和基础桌面界面、事件查询及记录导出；正式交付前继续验证真实场景、稳定性与新环境运行。

首版目标用户：需要回看固定视角监控视频、关注疑似火情事件的使用者。
首版流程：选择本地视频 -> 查看火焰/烟雾检测 -> 确认持续事件 -> 查看风险提示与原因 -> 查询/导出证据。

当前基线必须做到：

1. 模型在本机可加载，类别核验为 fire 与 smoke，CPU/GPU 推理可分别验证。
2. 视频读取、绘框、逐帧日志和输出视频形成闭环。
3. 输入缺失、权重缺失、视频无效时报告具体问题。
4. 每次运行记录模型来源、输入、参数和处理结果。

真实火情视频、无火视频与困难案例还需收集并核查使用权限。空白画面或自行生成的几何图形视频只能验证工程链路，不能证明识别准确率。

时序事件须按视频时间聚合并关联同类区域；短时缺失保留状态，结束输入正确关闭记录；确认依据与参数可追溯。已执行的验收见 docs/TEMPORAL_TEST_REPORT.md。

风险提示须以原始框并集覆盖、观察时间与平滑趋势等图像特征解释；仅评估确认事件，未确认和短时缺失要有清楚状态。保存分项贡献、配置与等级变化，避免频繁抖动。已执行验收见 docs/RISK_TEST_REPORT.md。

桌面版提供无需修改代码的视频选择、设备/阈值、启停、画面与曲线、事件确认截图、历史查询和记录 ZIP。后台与主线程分离，关闭前协作清理。已执行阶段验收见 docs/DESKTOP_TEST_REPORT.md；原生对话框和用户实际操作体验仍需试用。

后续验收以 PROJECT_PLAN.md 为准。暂不承诺屏幕火焰辨别、物理火势测量、经校准的火灾概率或工业消防部署能力。
