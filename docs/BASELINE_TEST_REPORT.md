# 初始检测基线测试记录

测试日期：2026-10-06。本记录只对应基础检测版本，不代表最终产品或真实火灾识别准确率。

## 环境

- Python 3.9.25，项目环境 `.venv-pytorch`，通过系统包继承复用 `D:\anaconda\envs\pytorch`。
- torch 2.8.0+cu128，torchvision 0.23.0+cu128。
- RTX 4060 Laptop GPU，约 8 GB 显存，CUDA 可用。
- Ultralytics 8.4.173、OpenCV 4.11.0、NumPy 1.23.5。
- `pip check`：No broken requirements found。
- 原有 Conda 环境保留，新增包安装在项目虚拟环境；曾在项目环境内安装 NumPy 1.26.4，发现与继承的 d2l 约束冲突后已改为 1.23.5。
- 曾开始下载独立 GPU PyTorch，发现已有环境后已停止，未完成该包安装。

## 权重与素材

权重为第三方公开模型，版本、SHA256 和文件大小见 models/manifest.json。
正例为 CC0 壁炉火焰视频，作者 BrillLyle；来源、SHA256 及核对过的 SHA1 见 videos/manifest.json，原始授权页面已保存。
无火工程视频由本项目本地生成，为 45 帧移动几何图形，不属于真实监控场景测试集。

## 已执行结果

| 检查 | 结果 |
|---|---|
| GPU 模型加载及空白图推理 | 通过，类别为 smoke/fire，空白图无检测框 |
| CPU 模型加载及空白图推理 | 通过，空白图无检测框 |
| 壁炉视频 GPU 无窗口处理 | 输出 206 帧，206 帧含检测；视频与日志帧数一致 |
| 壁炉逐帧检测输出 | 共 956 个 fire 框、4 个 smoke 框；未逐框标注或评估，不能据此声称准确率 |
| 几何图形视频 GPU 无窗口处理 | 完整输出 45 帧，无检测框；视频与日志帧数一致 |
| 日志索引和时间戳 | 连续帧序号，时间戳与帧序号/输入 FPS 一致 |
| 输出视频可解码性 | 两个结果视频均可完整重新解码 |
| 检测画面人工检查 | 已查看第一帧，有火焰框及一个 smoke 框；画面有多个重叠检测，尚未做时序/事件后处理 |

壁炉容器报告 207 帧，实际可解码 206 帧；原始下载 SHA1 与来源记录一致。程序把差异记录为 `completed_with_frame_count_warning`，没有将它隐去。

单次无窗口壁炉运行记录总耗时 3.245 秒，端到端约 63.484 帧/秒；包含初始化、解码、推理、绘制与编码。短片单次运行仅说明当前链路可运行，不作为稳定性能结论或纯推理速度。原始日志目录：outputs/run-20261006-163717-935432；无火工程检查：outputs/run-20261006-163723-337973。
