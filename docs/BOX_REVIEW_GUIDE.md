# 火焰 / 烟雾矩形框标注

## 打开工具

双击项目根目录 `start_box_review.cmd`，或在项目 PowerShell 运行：

```powershell
.\.venv-pytorch\Scripts\python.exe review_boxes.py
```

本次只标 27 张试点静态原图。左侧选择图片，顶部显示原视频、帧号及时间，可用原视频标注工具辅助查看上下文。工具不加载模型、不展示预测框。

## 每张图的操作

1. 填写审查人代号，例如 `R1`，不需要真实姓名或学校。
2. 在“画框类别”选择 `fire / 火焰`；鼠标左键从目标的一角拖到另一角。框会自动将火焰判断设为“有”。同一张图中每个明确分离的目标分别画框。
3. 切换 `smoke / 烟雾`，框出所有直接可见的烟雾。两类框可以重叠。
4. 分别检查下方“火焰”和“烟雾”：可见目标选“有”并有对应框；明确没有选“无”；无法可靠判断选“不确定”并填写原因。不能留“未判断”后勾选完成。
5. 勾选“已检查整张图，两类均已判断，并框出所有可见目标”，点击“保存并下一张”。完成最后一张时点击“保存”。

可以先保存未完成草稿。改变类别、备注或框后，工具会取消完成勾选，检查后再勾选。切换图片或正常退出会自动保存有效修改；另一个窗口已修改文件时会拒绝覆盖。

## 框画到哪里

- **火焰**：紧贴可见火焰整体的外接矩形，不把整个木堆、容器或建筑框进去。连成一片的火焰可以用一个框；明显分离的火焰用不同框。小火焰可放大到 2 / 4 倍后画，保存的是原图像素坐标。
- **烟雾**：框住可辨认的烟团范围。透明、边缘不规则的烟雾仍用矩形，不需要描轮廓；尽量减少无关背景，不把整幅图当成烟雾区域。烟散成彼此分离的区域时分别画框。
- **遮挡或出画**：只标当前画面中可见的范围，不补出想象中的完整形状。
- **不确定**：模糊小亮点、反光、喷射光、蒸汽或灰色背景不能仅凭颜色/燃烧常识当作火或烟。选“不确定”并写原因，后续整张图暂不用于监督训练。
- **无目标**：两类都明确不存在时，两项均选“无”，不画任何框，填写代号并勾选完成。空框本身不代表负例，必须有这两个明确判断。

框画错时点击框或下方列表选中，再点“删除选中框”；也可以“撤销最后一个框”后重画。删除某类最后一个框后，该类恢复“未判断”，需重新作出判断。缩放不会增加原图细节。

## 保存位置

- 新的框标注：`data/firesense/box-review-pilot-v1/annotations.json`，首次保存后创建。
- 旧版本备份：同目录 `box-history/`。
- 原图/来源清单：`images/`、`manifest.json`，工具只读。
- 原来的视频时间段标注：`data/firesense/review.json`，此工具不修改它。

关闭后重新打开会恢复已有标注。当前保存的是人工审查 JSON，尚未导出训练集或启动训练；后续先检查位置、完整性与不确定项，再进行统一转换。27 张试点不等于完整训练集。
